Privacy policy

steward — personal OAuth application · last updated 2026-11-12

Who this covers

This application has exactly one user: its owner. It is not offered to the public, has no sign-up, and cannot be used by anyone else.

What it accesses

With the owner's consent, it uses two Google API scopes on the owner's own account:

  • calendar — read events and create, update or delete the events it schedules.
  • tasks — read, create and update tasks.

No Gmail, Drive, Contacts or other Google data is requested.

Where data goes

Nowhere but the owner's machine. The application runs as a local service on the owner's home server. OAuth tokens are stored on that machine with file permissions restricted to the owner. No analytics, no telemetry, no third-party servers, no advertising, no sale or sharing of data.

Retention and removal

Tokens remain until the owner deletes them or revokes access at myaccount.google.com/permissions. Revoking access stops all further use immediately.
