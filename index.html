steward

A personal, single-user automation for one Google account.

This site exists because Google requires a public application home page before a personal OAuth client can be moved to production mode. The app itself is a local service running on the owner's own home server. It reads the owner's Google Calendar and Google Tasks to organise a weekly plan, using the owner's own OAuth credentials.

It is not distributed, has no other users, and stores nothing off the owner's machine. Scope use is limited to calendar and tasks.
